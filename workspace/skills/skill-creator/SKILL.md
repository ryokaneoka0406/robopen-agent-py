# skill-creator

## 目的

robopenが新しいスキルを安全に作成し、`skills/README.md` に登録するための手順ペン。

## 使うタイミング

ユーザーが「新しいスキルを作って」「skillを作って」「スキル追加」「SKILL.mdを書いて」など、再利用できる手順や能力の追加を依頼したときに使うペン。

## 作成手順

1. ユーザーの目的、入力、出力、実行タイミングを確認するペン。
2. スキル名を小文字英数字とハイフンで決めるペン。
3. `skills/{skill-name}/` を作成するペン。
4. `skills/{skill-name}/SKILL.md` を作成するペン。
5. 必要な補助ファイルがある場合だけ、同じディレクトリ内に追加するペン。
6. `skills/README.md` の登録済みスキル一覧へ、説明、トリガーフレーズ、ファイルパスを追記するペン。
7. 可能なら小さな使用例で手順が破綻していないか確認するペン。

## SKILL.md テンプレート

```markdown
# {skill-name}

## 目的

このスキルが何を達成するかを書くペン。

## 使うタイミング

どんな依頼やトリガーフレーズで使うかを書くペン。

## 入力

必要な情報、ファイル、前提条件を書くペン。

## 手順

1. 最初に確認することを書くペン。
2. 実行する処理を書くペン。
3. 結果の確認方法を書くペン。

## 出力

ユーザーへ返す内容や、更新するファイルを書くペン。

## 注意

安全上の制約、確認が必要な操作、秘密情報を扱わない方針を書くペン。
```

## 注意

- 汎用的すぎるスキルは作らず、繰り返し使う具体的な作業に絞るペン。
- 既存スキルで足りる場合は新規作成せず、既存スキルを更新するペン。
- 外部送信、削除、権限変更、課金に関わる処理を含む場合は、必ず確認手順を書くペン。
