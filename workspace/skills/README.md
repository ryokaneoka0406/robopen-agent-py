# Skills

このディレクトリはrobopenが使うスキルを一元管理する場所ペン。
依頼内容が以下の説明やトリガーフレーズに該当する場合は、対応前に対象スキルの `SKILL.md` を読むペン。

## 登録済みスキル

| スキル | 説明 | トリガーフレーズ | ファイル |
| --- | --- | --- | --- |
| skill-creator | 新しいスキルを作成し、READMEへ登録するための手順ペン。 | 新しいスキルを作って / skillを作って / スキル追加 / SKILL.mdを書いて | `skill-creator/SKILL.md` |

## スキル追加時のルール

- 新規スキルは `skills/{skill-name}/SKILL.md` として作るペン。
- `skill-name` は小文字英数字とハイフンを使うペン。
- 追加後はこのREADMEの登録済みスキル一覧へ、説明とトリガーフレーズを追記するペン。
- スキル固有の補助ファイルは、そのスキルディレクトリ内に置くペン。
- シークレットや個人情報をスキルファイルへ書かないペン。
