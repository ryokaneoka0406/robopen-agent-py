# 横断タスク: 安全性と運用設計

## タスクの内容
- APIトークン管理（dotenv）と秘密情報非コミットルールを整備する。
- Raspberry Pi上のsystemd serviceでは `.env` を `EnvironmentFile` で読み込み、実tokenをserviceファイルやリポジトリに埋め込まない。
- journaldで起動失敗・Slack疎通エラー・Codex実行エラーを追跡できる運用手順を整備する。
- Grafana CloudのRaspberry Pi integration用tokenは `/etc/robopen/grafana-cloud.env` に分離し、Alloyのsystemd drop-inからEnvironmentFileとして読み込む。
- SQLite (`data/agent.db`) の日次バックアップと復元手順を整備する。
- Codex利用上限の監視と残量閾値による自動スキップ制御を実装する。
- MemoryHigh/MemoryMaxおよび日次再起動運用を定義する。
