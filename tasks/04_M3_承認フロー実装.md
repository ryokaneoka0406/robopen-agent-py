## メモ（2026-05-14）
- 当初のラッパー側ルールベース実装（PR #14）はクローズ。理由は以下:
  - 入力テキストへの正規表現マッチでは誤検知（自然文中の `delete` 等）と見逃し（Codex が実行段階で生成する `unlink` 等）が同時に発生する。
  - 承認対象が「Codex が実行しようとしているコマンド」ではなく「ユーザー入力文字列」になり、設計ドキュメントの「rm系操作で必ず確認が走る」を厳密には満たさない。
- 再設計方針: Codex app-server / MCP の `approvalPolicy: "on-request"` イベントを Slack の Block Kit ボタンへ橋渡しする。詳細は M6 タスクで扱う。
- 本タスクは M6（Codex app-server 移行）完了後に再開する。
